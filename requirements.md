# Task Management System - Requirements

## 1. Project Overview

A task management application where users can create projects,
manage tasks, assign tasks to team members, and track progress.

There are two main roles:

- Admin
- User

## 2. Authentication

- User registration
- User login
- User logout
- Get current authenticated user
- Protected routes
- Role-based authorization

## 3. Users

### Admin
- View all users
- View user details
- Create users
- Update users
- Delete users
- Change user role

### User
- View own details
- Update own details
- Delete own account

## 4. Projects

- Create project
- Update project
- Delete project
- View project details
- Add/remove project members

## 5. Tasks

- Create task
- Update task
- Delete task
- Assign task to a user
- Change task status
- Change task priority
- Set due date
- Search tasks
- Filter tasks
- Sort tasks
- Pagination

## 6. Comments

- Add comment
- Edit own comment
- Delete own comment

## 7. Dashboard

Show:

- Total tasks
- Pending tasks
- In-progress tasks
- Completed tasks
- Overdue tasks
- My assigned tasks
